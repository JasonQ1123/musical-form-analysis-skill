# 曲式分析 — Agent Skill

[English](README.md) | 简体中文

这是一个可移植、以证据为依据的曲式分析 skill：把主题、调性、终止和结构功能联系到可核查的结构图；证据不足之处保留未决，不给出虚假的确定结论。

技能加载入口为带有 YAML `name`、`description` 字段的 [SKILL.md](SKILL.md)，正文的中文对照版为 [SKILL.zh-CN.md](SKILL.zh-CN.md)。它们均为普通 Markdown，可供兼容的技能加载器使用。读谱、听音、MIDI 解析和资料检索依赖宿主环境的工具，本仓库不实现这些工具。

## 解决什么问题

本 skill 针对以下常见误判：

1. 把伴奏音型的返回当作主题再现；
2. 把休止或乐段内部的 V–I 进行直接当作终止；
3. 混淆主题材料与主要结构部分；
4. 只凭返始记号、段落长度或闭合的中段判断曲式；
5. 在证据不足时给出精确小节号和终止类别；
6. 混淆材料关系与结构功能：变形动机未必构成新主题或结构性再现，连接也未必构成第三个主要部分；
7. 只给终止名称、不交代和声依据，或用猜测的公式支撑确定的终止及闭合判断。

分析时区分观察与解释，先检查全曲组织，再处理内部层级，并比较有依据的不同读法。

## 安装

以下命令使用 DSH 的技能目录。其他兼容宿主请使用其配置的技能目录。

用户级安装（所有项目可用）：

~~~bash
git clone https://github.com/JasonQ1123/musical-form-analysis-skill.git
mkdir -p ~/.dsh/skills
cp -r musical-form-analysis-skill ~/.dsh/skills/musical-form-analysis
~~~

项目级安装：

~~~bash
mkdir -p .dsh/skills
cp -r musical-form-analysis-skill .dsh/skills/musical-form-analysis
~~~

`name` 字段标识技能，安装目录名保持为 `musical-form-analysis`。中文文件是同一技能的阅读对照版，默认加载入口仍为 `SKILL.md`。

## 使用

可直接用中文或英文提出问题，例如：

- “这首曲子是什么曲式？”
- “单三还是复三？”
- “单二还是单三？有没有再现？”
- “是不是奏鸣曲式？”
- 附上乐谱并要求：“分析曲式，标出调式转变的小节和终止式。”
- “Analyse this score in English, including key changes and cadences.”

分析会先确认资料来源和小节定位，再核对主题、调性、终止与结构层级，最后给出有证据支持的结构图和结论。只有存在小节级证据时才列小节表；只有曲名不能作为虚构分段的依据。

有谱面依据时，默认输出简明图表：大段括线下依次列乐句、主体小节、小节数、调性／调式、终止到达、终止式和终止类型。调性或调式变化必须标明出现的小节／拍位及新调名，无变化和未确认部分分别注明。终止式简写为 `D⁷—T，完满全终止` 等，并附必要的证据短注。工具允许时生成 PNG 简图及相应 Markdown 报告，默认保存在资料／项目目录之外，除非用户指定其他位置。[固定格式说明](references/compact-analysis-format.zh-CN.md)约定布局和符号，不预设某首作品的曲式、调名或乐句长度。

**分析结果既可完整输出中文，也可完整输出英文。** 用户明确指定语言时优先遵从，否则跟随提问语言。标题、图表字段、调名、终止类别、图例、注释和最终回复一起切换；音乐符号与证据标签保持不变。只有明确要求双语结果时，才同时列两种语言。固定格式说明提供[中文版](references/compact-analysis-format.zh-CN.md)和[英文版](references/compact-analysis-format.md)。

## 内容

[技能正文](SKILL.zh-CN.md)包含：

- 乐谱、音频、MIDI、文字描述及仅有曲名等不同输入的处理方式；
- 谱面、录音、MIDI、文献、转述与分析推断的证据标签；
- 结合语境判断分界与再现，不设置通用的小节长度门槛；
- 有依据的终止公式，如 K46–D–T、D–T、S–D 或罗马数字等价式，并分别保留和声、终止类别及闭合判断的不确定性；
- 调性／调式变化的小节与拍位，区分转调、短暂主化和半终止，以及固定的中英文简图／简表格式；
- 分别标材料身份与结构功能：由 a 衍生的片段可以承担连接，而不一定是新主题或结构性再现；
- 在照片可读性需要时裁切或校正，按音高、节奏与声部判断材料，避免只比像素；
- 从定位、终止、材料与调性到结构层级、曲式判断和输出的流程；
- 奏鸣曲式、回旋曲式、变奏、巴曲式、拱形及通谱式等整体组织的判断依据；
- 二部／三部、调性闭合、主题再现、结尾对应及内部层级的区分；
- 最终核查清单和中英术语表。

[合成判断案例（英文）](examples/decision-cases.md)给出明确的输入事实和预期推理，覆盖连接材料变形、终止公式未知、倾斜谱面比较等问题。这些是构造案例，不是对真实作品的事实声称，也不验证读谱或图像处理准确性。

[门德尔松证据审查（英文）](examples/mendelssohn-op72-no2.md)替代早先未经核实的分析。该案例没有配套的乐谱、录音或可检索支持文献，因此不能据此确定该作品的曲式、终止表或小节数。

## 合成事实的输出示例

假设提供的描述明确说明：第一反复部分结束于属调，第二反复部分末尾把第一部分的结尾旋律调整到主调，而开头主题没有再现。

> 提供的描述支持连续性、结尾对应的二部曲式（continuous, balanced binary）[reported, inferred]。第一反复部分没有在主调上闭合，第二部分结尾把第一部分的收尾材料调整到主调[reported]。“Balanced”指结尾材料的对应，不是两个部分长度相等[inferred]。由于描述明确指出开头主题没有结构性返回，再现二部的依据较弱[reported, inferred]。这一读法尚未用乐谱核对。

## 适用范围与限制

- 终止术语主要沿用共性写作时期的调性音乐惯例；其他曲目应调整方法，教材术语影响结论时明确说明。
- 曲式类别可以存在层级：回旋主部或三声中部内部仍可采用二部结构，不要求一个标签包办所有层级。
- 重点是段落层面的曲式；和声和动机细节应服务于这一任务，不默认扩展为完整的逐和弦分析。
- 现有案例验证的是根据给定事实进行推理及保留证据限制，不构成真实作品的经读谱核实基准。
