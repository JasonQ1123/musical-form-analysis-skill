# 曲式分析固定简式

[English](compact-analysis-format.md) | 简体中文

用于分析结果的呈现。固定字段、顺序和记号写法，分析数值仍须逐曲核对。**分析结果既可完整输出中文，也可完整输出英文**：优先按用户明确指定的语言，否则随用户提问的语言。图表标题、字段、调名、终止类别、图例、注释和最终回复同时切换；音乐符号及证据标签保持不变。只有用户要求双语结果时，才同时列两种语言。用户明确要求别的版式时按其要求调整，证据约束不变。

## 输出语言对照

文档语言不决定分析结果语言：使用这份中文说明也可以生成全英文结果，反之亦然。

| 中文字段／写法 | 英文字段／写法 |
| --- | --- |
| 大段括线 | Section brackets |
| 乐句 | Phrase |
| 主体小节 | Core bars |
| 小节数 | Bar count |
| 调性／调式 | Key / mode |
| 终止到达 | Cadential arrival |
| 终止式 | Cadential formula |
| 终止类型 | Cadence type |
| 大段／乐句 | Section / phrase |
| 长度 | Length |
| 终止式与类型 | Cadential formula and type |
| 第N小节（必要时注明拍位）→ 新调性／调式 | m. N (beat, if needed) → new key / mode |
| 降E大调；c小调；D多利亚调式 | E-flat major; C minor; D Dorian |
| 完满全终止；不完满全终止；半终止 | Perfect authentic cadence (PAC); imperfect authentic cadence (IAC); half cadence (HC) |
| 未确认；暂定；连续衔接／无独立终止 | Not verified; provisional; continuous join / no independent cadence |

英文图中可用 `PAC`、`IAC`、`HC` 缩短单元格，并在图例展开名称；中文图默认写中文类别。英文也可保留同一套T／S／D符号，例如 `D⁷—T, PAC`，图例分别解释为 tonic／subdominant／dominant。不要只译标题而保留另一语言的字段和说明。

## 1. 开头两项

1. **曲式：**一句话写曲式及必要限定，如“有变化再现的单三部曲式；中段单独反复”。这只是句式示例，不能套用曲式结论。
2. **调性／调式：**主调＋变化清单。不要用大段和声论述代替明确的小节位置与新调名。

有确证变化时，每项按下式写；以下为字段格式，不是某首作品的已知事实：

```text
第N小节（必要时注明拍位）→ 新调性／调式
第M小节 → 回到主调（写出完整调名）
```

- 调名包含主音及大小调／调式，如“降E大调”“c小调”“D多利亚调式”，不能只写“属调”或只写一个字母。
- 英文结果使用对应句式 `m. N (beat, if needed) → new key / mode`，调名完整写作 `E-flat major`、`C minor` 等；回归写作 `m. M → return to [full home-key name]`。
- 分别识别转调、同主音大小调转换、短暂主化，以及属功能停留。临时变音、力度／织体改变、对比段开始和半终止，均不能单独证明转调。
- 有渐进转调或枢纽和弦时，分别注明可确认的变化区间和确立位置；不能确认起点时写“第N—M小节逐步转向……”，不要补猜精确起拍。
- 短暂主化但未建立新调时，写“第N小节：短暂主化……；未确立转调”，不把它混入已确认转调清单。
- 已核对全曲且未发现变化时，写“全曲为……；未发现可确认的转调或大小调转换”。若仅部分可读，则写“可辨部分为……；第N—M小节未确认”，不据此断言全曲无变化。
- 英文对应写作 `The piece remains in [key]; no confirmed modulation or change of mode`；部分未决写 `Readable passages are in [key]; mm. N–M are not verified`。
- 调式内部的自然／和声／旋律形态，只有谱面支持且确实有分析意义时才注明，不仅凭调号判定。

## 2. 简图的固定布局

图顶为曲式名称、实际演奏的大段次序及简短调性结论。用括线标大段；每列对应一个可确认的乐句／适当层级的单元，以下行序保持不变：

```text
             大段括线（例如 A、B、A′，按实际曲式设置）
乐句         材料标记，如 a、a′、b
主体小节     与下方编号说明一致的谱面范围
小节数       该单元的实际主体长度
调性／调式   完整调名；句内变化还须标变化小节
终止到达     到达小节，必要时带拍位
终止式       简短功能公式
终止类型     中文类别；不清楚则明确未确认
```

固定的是行序，不是列数、段数或四小节／八小节长度。连接、扩充、缩减、非终止性接合及共享小节如实展示；不能为了填表制造乐句或终止。上下层级、谱面范围和演奏反复次序必须分清。

图面保持白底、清楚的括线和列对齐。调性行可以淡色突出，避免图例装饰挤占内容。转位数字用可读的上下标；字体不支持 `a‴` 等字符时改用 `a'''`，不得留下方框或漏字。列多时增加画布宽度或分图，不压缩到难以阅读。

## 3. 对照简表的固定列

```text
大段／乐句 | 主体小节 | 长度 | 调性／调式 | 终止到达 | 终止式与类型
```

- 每行对应图中同一单元，所有调名、小节、长度、公式和类型须与图一致。
- 主体范围与弱起可以分别写，但须在编号说明中给出弱起位置。终止到达用其实际位置，不默认等于范围末端或最后一个音。
- 单元内若有调性变化，在“调性／调式”格内写“原调 → 新调（第N小节）”；即使不在段首也不能省略。回到主调同样标小节。
- 对非终止性段界写“连续衔接／无独立终止”；和声不清写“公式未确认；终止类型未确认”。调名、公式、类别可以有不同确定性，分别保留。
- 支撑某个判断的最少旋律／低音、转位及闭合层级说明放在表下短注，不必为每项新增宽列。存在争议时在对应格注明“暂定”，并简述会影响结论的证据缺口。

## 4. 终止式的固定写法

默认用 **T／S／D 功能记号＋必要的转位或七音＋中文终止类型**，全表记号一致。如需要级数校核，可在短注给罗马数字等价式，不并列堆满每个单元格。

| 写法示例 | 使用条件 |
| --- | --- |
| `D⁷—T，完满全终止` | 属七到主，两和弦均为原位，旋律到达主音，具有终止功能 |
| `D⁷—T，不完满全终止` | 两和弦为原位、旋律到主和弦三音／五音的属七到主终止；涉及转位时按实际改写公式 |
| `T—D⁷，半终止` | 已核对这一路径，乐句结束在属七和弦；不是进入属调的证据 |
| `S—D，半终止` | 已核对下属到属及句末功能；不因它更像模板而替换实际路径 |
| `K⁶₄—D⁷—T，完满／不完满全终止` | 终止四六及后续和弦均已核对；按实际到达分别判类别 |

这些仅说明记号和条件，不提供可套用的终止答案：

- T为主功能，S为下属功能，D为属功能，D⁷为属七；K⁶₄为终止四六（纯文本可写 `K46`，必须注明表示6/4）。D⁷不能替代普通属三和弦D，不能把每个终止统一补成 `K⁶₄—D⁷—T`。
- 实际转位、和弦性质必须保留。若T／S／D不能清楚表达小调、其他调式或特殊和声，用已说明的罗马数字／适当体系，不能强套大调公式。
- **公式与类型分开核对。** 同样的 `D⁷—T` 可以支持不同的全终止类型；还须看低音、旋律到达、转位与乐句功能。内在属—主进行不自动构成终止。
- 半终止、变格终止、阻碍终止、规避／中断终止等按实际证据写，不强迫二选一“完满／不完满”。和声未知时，依赖它的类别及调性闭合判断也须保留未决。

每份简图／简表只需用一条短图例解释本次实际使用的记号，并用一至数条到达音短注支持容易混淆的类别。用户未要求详细和声时，不逐拍列经过和弦与装饰音。

## 5. 编号、反复与证据短注

图表下至少交代会影响定位的事项：

- 谱源文件／书页／系统，以及采用原谱小节号还是自编号。自编号时核对每行小节数；完整的“先休止、后进旋律”小节与真正不完全弱起小节分别处理，不固定把开头算第0或第1小节。
- 反复是否展开；一、二房子的编号与路线；D.C.／D.S.等实际导航。不要把替代结尾多算为一个连续乐句。
- 弱起的实际位置、段中进入的拍位、段落共用小节。主体长度与包含弱起的范围分别说明，共享小节在总数中只计一次。
- 来源／观察用 `[score]`、`[audio]`、`[midi]`、`[lit]`、`[reported]`；曲式、调性、终止分类等判断用 `[inferred]` 并给支持。标签可统一覆盖图表中明确指认的一组字段，定位仍须可查。

## 6. 交付与保存

有充分证据且可渲染时，默认交付一张结构简图PNG及与其一致的简明Markdown报告；最终回复给出PNG的绝对本地路径预览和实际文件链接。先打开PNG检查中文、上下标／撇号、对齐和裁切；不要只返回工具生成成功的信息。无渲染工具时用同字段的文本图／表，说明没有生成图片。

分析产物、裁图和临时文件默认放在**被分析资料／当前项目之外**，优先使用会话约定或平台指定且位于项目外的输出目录；无约定时可用用户文档目录下的 `CodexOutputs/musical-form-analysis/`。不硬编码某位用户的用户名或绝对路径。用户明确指定别处时遵从。此规则约束分析产物，不阻止用户授权的skill源文件修改。

固定格式不覆盖主skill的证据要求。只有标题或无法确认小节的输入，给有限结论及缺失依据，不生成有虚构小节、调性变化或终止类别的完整图表。
